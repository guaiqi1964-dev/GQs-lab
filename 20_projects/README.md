# 20_projects — 能拿得出手的项目

**有名字、有完成度、将来可能长久维护的东西。**

## 归这里
- 有独立 README 的完整项目
- 工具 / 库 / 小应用，哪怕只有几百行
- 一次做成、打算长期留着的东西

## 不归这里
- 半成品试水 → 先放 [`30_experiments/`](../30_experiments/)
- 项目长大了、值得独立成仓库 → 那就**搬出去新建仓库**，
  在这里的 README 留一行链接即可（本仓库只放"不知道该传哪"的东西）
