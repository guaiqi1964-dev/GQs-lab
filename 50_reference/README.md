# 50_reference — 参考资料收藏

**从别处收集来的、将来可能要查的东西。**

## 归这里
- 手册 / 速查表（cheat sheet）、协议说明
- 规范、API 文档快照
- 优质文章存档、教程 PDF
- 配置模板、常用命令备忘

## 不归这里
- 大体积数据集 / 模型权重（**不要进 Git**，见下）
- 网上随处可查、你自己不会再看的东西 —— 别存

## 注意体积
Git 仓库会永久保留历史，大文件一旦提交就很难清掉。
以下内容请**不要**提交，改用网盘 / Release 附件：
> 二进制安装包、模型权重（`.gguf`/`.safetensors`）、数据集、
> 超过 ~10 MB 的 PDF 或压缩包。

## 版权
放进来时请注明来源（URL / 作者 / 许可）。
本仓库公共可见，不确定授权的内容就不要传。
