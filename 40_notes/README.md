# 40_notes — 笔记与踩坑记录

**你自己写下来的文字**，不是代码。

## 归这里
- 技术笔记、学习整理、思维导图导出
- 踩坑记录 / 故障排查过程（"这个报错到底为什么"）
- 读书笔记、课程笔记
- 想法草稿、方案对比

## 不归这里
- 从别处抄来的资料 → [`50_reference/`](../50_reference/)
- 一份文件就能说完的短记录 → 直接丢根目录也行，不必强求归档

## 命名建议
`YYYY-MM-DD_主题.md`，例如 `2026-10-11_windows-权限踩坑.md`。
按日期前缀的好处：目录里自然按时间排序，找"上个月那件事"很快。
