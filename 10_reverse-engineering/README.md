# 10_reverse-engineering — 逆向工程

**分析已有程序 / 文件格式 / 协议的产物。**

## 归这里
- 从 EXE / DLL / 固件里还原出来的源码或结构说明
- 反汇编脚本、反编译器配置、`.pdata`/符号表解析工具
- 逆向分析笔记、函数表、字符串提取结果
- CTF 逆向题解与 writeup

## 不归这里
- 你自己**从零写**的程序 → [`20_projects/`](../20_projects/)
- 只是拿别人的库来用 → [`30_experiments/`](../30_experiments/)
